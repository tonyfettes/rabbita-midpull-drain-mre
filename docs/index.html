rabbita: the counter that freezes after a tab switch

A counter with two tabs. Each tab component pings the counter store once when it mounts (a no-op observer message).
  1. Click +1 a few times — works normally.
  2. Click switch tab, then +1 again — the counter is frozen. The store log below shows the model still counting.
  3. Click switch tab again — the counter suddenly catches up.
